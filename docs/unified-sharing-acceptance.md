# 三类内容分享联合验收（隔离环境）

## 已接入开发分支
- 文章专区：公开文章详情内的「分享」按钮，指向 `/member-articles.html#article=<uuid>`。
- 论坛：公开帖子详情内的「分享」按钮，指向 `/forum.html#post=<uuid>`。切换帖子时必须更新目标 ID。
- 福音音频：每条录音旁的「分享」按钮，指向 `/gospel.html#audio=<sermon-id>`，打开时定位录音行，不分享音频下载 URL。
- 手机支持 `navigator.share` 时优先系统分享；其他浏览器通过剪贴板复制。
- 文章/论坛的动态 OG Worker 尚未部署；当前按钮使用可访问的原始页面地址，因此社交平台暂时只可能显示栏目级默认卡片。
- 音频当前只有独立定位链接，没有每条录音的服务端 OG 卡片。

## 必须在独立预览中人工验证（未完成）
1. 文章：已发布文章能分享并打开同一篇；草稿/待审核文章不显示为公开内容；上一篇/下一篇、阅读、点赞、评论、返回功能不变。
2. 论坛：A/B 两篇帖子连续切换，分享按钮对应当前帖子；被隐藏、删除、未审核帖子不能被访客公开读取；评论、举报、返回正常。
3. 福音音频：旧版 51 讲和新上传录音均有独立分享按钮；打开链接定位正确行；播放器、试听、会员下载权限不变。验证通过播放器容器 `player.html?page=...` 的跳转路径。
4. 移动端：iOS Safari、Android Chrome 调用系统分享或正确回退；取消系统分享不显示错误；电脑 Chrome/Safari/Edge 复制链接可打开。
5. 多语言：中文、英文、韩文、日文下按钮和成功/失败提示；语言动态切换后文字刷新。
6. 无障碍：键盘 Tab 可聚焦、按钮标签明确；窄屏不会遮挡播放器或帖子操作按钮。
7. Cloudflare：独立 workers.dev 部署后，用真实公开/草稿/不存在 UUID 验证 200/404；微信、X、Facebook 抓取器验证单篇 OG；生产域名路由不覆盖。

## 发布门槛
- 所有 GitHub Actions 检查通过并且独立浏览器验收通过。
- 确认 Worker 的预览域名、测试库、发布权限及分享 URL 切换方案。
- 未达到上述条件时保持 PR #26 草稿，不合并到 main，不修改正式 Supabase 或 Cloudflare 路由。
