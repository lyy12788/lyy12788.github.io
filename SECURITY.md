# Security Policy / 安全漏洞报告

## Reporting a vulnerability / 报告安全漏洞

Please **do not** disclose security vulnerabilities, credentials, access tokens, personal information, or proof-of-concept exploits in public GitHub issues, pull requests, or forum posts.

请勿在公开 Issue、Pull Request 或论坛中发布安全漏洞细节、密码、API 密钥、个人资料或攻击演示。

Use the repository's **Security → Advisories → Report a vulnerability** private reporting flow when available:

https://github.com/lyy12788/lyy12788.github.io/security/advisories

如果私人漏洞报告功能尚未启用，请等待站长开通后再通过该渠道提交；不要使用公开 Issue 传送敏感信息。

## Scope / 适用范围

This policy covers the public website source and integrations maintained in this repository. Do not attempt to access, extract, or modify other members' data when testing. Test only with accounts and data you own or have explicit permission to use.

本政策适用于本仓库维护的网站代码及相关集成。测试时只能使用自己拥有或获得明确授权的账号与数据，不得访问、提取或修改其他会员的信息。

## Response / 处理方式

Reports will be assessed according to impact and reproducibility. No response-time or bounty commitment is made.

站长将根据风险程度与可复现情况评估报告；目前不承诺固定响应时间或漏洞奖励。
